Choose the Windows folder ZIP or Apple Silicon Mac DMG. Both packages support English and Korean in the app. [Release files](https://github.com/a123qsd/calclens/releases/tag/v0.9.1) · [Desktop guide](DESKTOP.md)

## 한국어

| 운영체제 | 파일 | 실행 방법 |
| --- | --- | --- |
| Windows x64 | [CalcLens 폴더 ZIP](https://github.com/a123qsd/calclens/releases/download/v0.9.1/CalcLens-0.9.1-Windows-x64-folder.zip) | ZIP 전체를 새 폴더에 풀고 `runtime` 옆의 `CalcLens.exe`를 실행합니다. |
| Apple Silicon Mac | [CalcLens DMG](https://github.com/a123qsd/calclens/releases/download/v0.9.1/CalcLens-0.9.1-macOS-Apple-Silicon.dmg) | DMG를 열고 CalcLens를 응용 프로그램 폴더에 옮긴 뒤 실행합니다. |

Windows에서는 압축을 푼 폴더 전체를 함께 보관하세요. 다음 실행부터 같은 런타임을 사용합니다. 새 버전은 별도 폴더에 풀어야 합니다. 첫 화면에 그래핀 구조가 나타납니다. **CIF 열기**로 파일을 선택하거나 창에 끌어 놓으세요. 두 배포판 모두 Python과 필요한 라이브러리를 포함하며, 로컬 작업은 인터넷 연결 없이 사용할 수 있습니다.

Windows 실행 파일에는 게시자 서명이 없습니다. Mac 앱은 Apple Silicon용으로 로컬 서명했으며 Apple 공증은 받지 않았습니다. 받은 ZIP 또는 DMG의 해시를 [파일별 SHA-256](https://github.com/a123qsd/calclens/releases/download/v0.9.1/SHA256SUMS.txt)과 비교할 수 있습니다. ## English

| Platform | Download | Start CalcLens |
| --- | --- | --- |
| Windows x64 | [CalcLens folder ZIP](https://github.com/a123qsd/calclens/releases/download/v0.9.1/CalcLens-0.9.1-Windows-x64-folder.zip) | Extract the complete ZIP into a new folder, then open `CalcLens.exe` beside `runtime`. |
| Apple Silicon Mac | [CalcLens DMG](https://github.com/a123qsd/calclens/releases/download/v0.9.1/CalcLens-0.9.1-macOS-Apple-Silicon.dmg) | Open the DMG, drag CalcLens into Applications, then launch it. |

On Windows, keep the whole extracted folder together. Later launches reuse its runtime. Extract each upgrade into a separate folder. The desktop opens with a graphene example. Choose **Open CIF** or drag a file into the window. Both builds include Python and support offline use. Select English or Korean in the app.

The Windows launcher is unsigned. The Mac app is ad-hoc signed and has no Apple notarization. Compare the downloaded ZIP or DMG with the [SHA-256 checksums](https://github.com/a123qsd/calclens/releases/download/v0.9.1/SHA256SUMS.txt).
