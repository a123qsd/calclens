## English

| Platform | Download | Start CalcLens |
| --- | --- | --- |
| Windows x64 | [CalcLens EXE](https://github.com/a123qsd/calclens/releases/download/v0.9.0/CalcLens-0.9.0-Windows-x64.exe) | Double-click the downloaded file. |
| Apple Silicon Mac | [CalcLens DMG](https://github.com/a123qsd/calclens/releases/download/v0.9.0/CalcLens-0.9.0-macOS-Apple-Silicon.dmg) | Open the DMG, drag CalcLens into Applications, then launch it. |

The desktop opens with a graphene example. Choose **Open CIF** or drag a file into the window. Both builds include Python and support offline use. Select English or Korean in the app.

The Windows EXE is unsigned. The Mac app is ad-hoc signed and has no Apple notarization.
