# 네이티브 그래픽과 이미지 출력

기준 커밋 `d6e9acf`의 Qt 뷰어는 표면을 먼저 그린 뒤 모든 원자를 그렸다. 따라서 불투명 표면 뒤의 원자가 보이고 선택되었다. 삼각형의 평균 깊이로 정렬하는 방식은 서로 교차하는 표면도 올바르게 표현하지 못했다.

현재 뷰어는 원자 구, 셀과 거리 가이드, 간격 평면, 전자 표면의 깊이를 픽셀마다 계산한다. 불투명 표면은 뒤의 원자와 가이드를 가리며 원자 선택도 막는다. 반투명 표면은 각 픽셀의 깊이 순서로 합성한다. 반투명 표면을 통해 보이는 원자는 선택할 수 있다. 원자의 중심 깊이만 비교하지 않으므로 평면과 구가 교차하는 장면에서도 구의 앞부분만 보인다. 표면의 공통 삼각형 변은 한 번만 합성하여 대각선이 진해지는 현상을 막는다.

NumPy로 작은 타일을 계산하고 Qt로 화면과 설명을 그리는 소프트웨어 렌더러다. 삼각형을 묶어 처리하며, 겹치는 표면이 많으면 타일을 더 작게 나누어 모든 투명 층을 유지한다. 계산 장치 설정의 Metal/CUDA와 그래픽 설정은 서로 독립적이다.

## 품질 설정

| 설정 | 정지 화면 표본 배율 | 회전·확대 중 배율 | 구의 음영 | 최대 원소 라벨 |
| --- | ---: | ---: | --- | ---: |
| 가벼움 | 70% | 50% | 단색 | 40 |
| 균형 | 100% | 70% | 구 표면의 소프트웨어 음영 | 120 |
| 고품질 | 150% | 100% | 구 표면의 소프트웨어 음영 | 240 |
| 자동 | 장면 복잡도와 실제 프레임 시간으로 위 설정 중 선택 | 선택한 설정에 따름 | 선택한 설정에 따름 | 선택한 설정에 따름 |

고품질은 더 크게 그린 화면을 줄여 경계의 계단 현상을 줄인다. 균형과 고품질은 텍스트 안티앨리어싱과 이미지 축소 보간을 사용한다. 회전과 확대가 끝나면 정지 화면의 배율로 다시 그린다. 라벨은 선택한 원자를 우선하며, 라벨 수가 줄어도 원자 자체는 생략하지 않는다. 주변광 차폐, 그림자, 광선 추적은 구현하지 않았다.

자동은 처음에 균형을 사용한다. 원자 수와 표면 삼각형 수가 큰 장면은 가벼움으로 시작하며, 이후 최근 12개 프레임의 실측 시간을 참고한다. 평균 70 ms를 넘으면 가벼움으로 낮추고, 충분히 짧아지면 다시 높일 수 있다. 사용자가 수동으로 고른 설정은 자동 판단과 프로젝트의 카메라 복원으로 덮어쓰지 않는다.

모든 설정은 같은 원자 좌표, 원자 수, 전체 표면 삼각형을 사용한다. 격자 값을 재표본화하거나 물리적 등치값을 높여 품질을 낮추지 않는다. 표면 추출은 원본 격자의 요청 등치값에서 수행하며 30,000개 삼각형의 기존 보호 한도를 유지한다. 한도를 넘으면 명시적으로 거부하고 원본과 등치값을 보존한다.

공간 채움은 표시용 반지름을 사용한다. ASE의 반데르발스 반지름에 0.75 배율을 적용하고, 값이 없는 원소는 공유 반지름의 1.5배로 대체한 뒤 같은 표시 배율을 적용한다. 표시 크기로 전자밀도 경계나 분자 부피를 판정하지 않는다. 연결선은 표시된 원자 사이의 거리 가이드이며 화학 결합 판정이 아니다.

## PNG와 작은 화면

PNG는 화면 조작 품질과 별도로 고품질로 다시 그린다. 설정에서 고른 출력 폭과 배경을 사용하며 원본 격자·분석 결과는 변경하지 않는다. 투명 PNG의 장면 배경은 투명하고 과학 설명 영역은 흰색이다. 실제 파일 높이는 설명의 길이에 따라 늘어난다.

범례와 설명은 실제 텍스트 레이아웃으로 높이를 계산한다. 긴 파일명과 해시는 줄을 바꾸며, 전체 출처는 PNG의 `CalcLens provenance` JSON과 `CalcLens annotations` 텍스트에도 보관한다. 프로젝트·자료 ID, 원본 SHA-256, 물리량과 단위는 선택한 자료의 당시 기록에서 가져온다. 파생 차이 밀도에는 보관된 전체 계산 기록도 포함한다. 설명이 출력 한도를 넘으면 자르지 않고 오류를 알린다.

뷰어는 작은 높이에서 제목과 범례를 줄여 구조 영역을 확보한다. 비교 창은 683×384 논리 픽셀에서도 닫기 버튼이 보이며 긴 내용은 스크롤할 수 있다. 영어·한국어 창은 Mac Cocoa Retina(DPR 2)에서도 확인했다. Windows 125/150/200%에 대응하는 논리적 크기는 시험했고 실제 Windows 모니터 배율 전환은 미검증이다.

## 검증 재현

Qt와 NumPy가 설치된 환경에서 실행한다.

```sh
PYTHONPATH=src QT_QPA_PLATFORM=offscreen python -m pytest -q tests/test_native_graphics.py tests/test_native_desktop.py tests/test_desktop_research_panel.py
PYTHONPATH=src QT_QPA_PLATFORM=offscreen python scripts/capture_native_graphics.py --output /path/to/evidence --baseline-ref d6e9acf
PYTHONPATH=src QT_QPA_PLATFORM=offscreen python scripts/capture_native_graphics.py --output /path/to/evidence
```

캡처 도구는 기준 커밋의 실제 Qt 뷰어와 현재 Qt 뷰어를 실행한다. 불투명 평면의 앞뒤, 반투명 평면, 교차하는 반투명 표면, 원본 water Cube의 각 품질, 800/1600/3200 PNG를 저장한다. `graphics-before-observations.json`과 `graphics-after-observations.json`은 실제 환경, 선택 결과, 그린 크기와 프레임 시간을 기록한다. 합성 평면은 깊이 검사 장면이며 전자 계산 결과로 표시하지 않는다.

이번 검증 환경은 macOS ARM64, Python 3.12.16, PySide6 6.12.0, Qt offscreen이다. 앞의 불투명 평면 뒤 원자는 기준 뷰어에서 보이고 선택 ID가 `0`이었으며, 수정 후에는 가려지고 `-1`이었다. 평면이 뒤에 있거나 반투명하면 원자 ID `0`을 선택할 수 있었다. 픽셀 테스트는 교차하는 삼각형과 구, 가이드, 투명 층 240개의 합성도 확인한다.

water Cube는 30×30×30 원본 격자와 0.05 e/Å³ 등치값에서 7,624개 삼각형을 그대로 사용했다. 개별 오프스크린 프레임은 가벼움 약 122 ms, 균형 약 187 ms, 고품질 약 343 ms였다. 이 수치는 특정 캡처의 관찰값이며 프레임 속도 보장이나 Windows 성능 비교가 아니다. 표면이 복잡한 장면의 고품질 회전은 여전히 느릴 수 있다. Windows 하드웨어·GPU 렌더링 성능은 측정하지 않았다.
