# CalcLens 0.9.0 for Windows

1. Download the [Windows x64 EXE](https://github.com/a123qsd/calclens/releases/download/v0.9.0/CalcLens-0.9.0-Windows-x64.exe).
2. Double-click the EXE. Unpacking the bundled files can take a few seconds.
3. Once the graphene structure appears, choose **Open CIF** or drag a CIF into the window. Use the language selector to switch between English and Korean.

The EXE includes Python and Qt. Local work runs offline. Closing the app lets you save your changes. The EXE has no publisher signature. To verify your download, compare this PowerShell command's output to the [published SHA-256](https://github.com/a123qsd/calclens/releases/download/v0.9.0/SHA256SUMS.txt).

```powershell
Get-FileHash .\CalcLens-0.9.0-Windows-x64.exe -Algorithm SHA256
```
