# COD graphite case

See the [case study](../../docs/CASE_STUDY.md) for source attribution, CC0
reuse, preparation assumptions, direction checks, measured results, and the
independent geometric comparison.

- `source/9011577-rev291877.cif`: original, unmodified COD source; P63/mmc,
  two asymmetric sites. Prepare it before using CalcLens.
- `graphite_p1.cif`: four explicit bulk sites; its equal interlayer gaps
  require review and are not a unique vacuum assignment.
- `graphene_from_graphite_p1.cif`: two-site basal sheet with a chosen 20 Å
  repeat, centred at fractional z = 0.5; an unrelaxed constructed monolayer.
- `case_results.json`: provenance, hashes, environment, and measured comparison.

Source: P. Trucano and R. Chen, *Nature* 258 (1975), 136–137,
[doi:10.1038/258136a0](https://doi.org/10.1038/258136a0),
[COD 9011577](https://www.crystallography.net/cod/9011577.html), revision
291877, via AMCSD 0014675. COD data are [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
This data reuse status is separate from the CalcLens software license.
